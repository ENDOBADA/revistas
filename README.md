# Revistas · Endodoncia Badajoz

Hemeroteca de revistas de actualización en endodoncia, para profesionales de la odontología.
Selección y edición: Dr. Javier Nieto · https://endodonciabadajoz.blog

- `index.html` — portada: números semanales (Nº 1, Nº 2…) con «Marcar como leído», vista por tema, buscador y filtros
- `catalogo.json` — series, números semanales (`ediciones`) y revistas (`numeros`); cada revista lleva `artifact` con su origen y `edicion`. Lo lee también el Área Profesional (Actualización Endo).
- `CNAME` — dominio propio: https://revistas.endodonciabadajoz.com
- `numeros/` — cada revista en HTML

Se actualiza cada lunes tras la aprobación del Dr. Nieto.
