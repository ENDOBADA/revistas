# Revistas · Endodoncia Badajoz

Hemeroteca de revistas de actualización en endodoncia, para profesionales de la odontología.
Selección y edición: Dr. Javier Nieto · https://endodonciabadajoz.blog

- `index.html` — portada (vista por fecha o por tema, buscador y filtros)
- `catalogo.js` — lista de números; cada entrada lleva `artifact` con su origen
- `numeros/` — cada revista en HTML

Se actualiza cada lunes tras la aprobación del Dr. Nieto.
